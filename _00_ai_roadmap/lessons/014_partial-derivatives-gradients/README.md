# Lesson 014 — Partial Derivatives, Gradients & Jacobians

**Module:** 3 — Linear Algebra & Calculus
**Prerequisites:** [013](../013_calculus-derivatives/README.md)
**Estimated time:** 2 hours

## Objective

Real models have millions of parameters, not one — this lesson extends
derivatives to functions of many variables (partial derivatives, gradients,
Jacobians), directly setting up Gradient Descent (Lesson 015) and
backpropagation (Lesson 037).
