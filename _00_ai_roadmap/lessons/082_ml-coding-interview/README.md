# Lesson 082 — ML/DS Coding Interview Prep

**Module:** 15 — Productionization & Career Transition
**Prerequisites:** [081](../081_ml-system-design-interview/README.md)
**Estimated time:** 2–3 hours

## Objective

The other half of the ML interview loop: not "design the system" but
"implement this algorithm on a whiteboard/shared doc, from scratch, in
20 minutes." This lesson catalogs the recurring question categories and
gives practice implementing classic ML building blocks without a
library, exactly as you'd need to in the room.
