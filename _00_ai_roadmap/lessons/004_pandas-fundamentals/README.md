# Lesson 004 — Pandas Fundamentals

**Module:** 1 — Programming & Data Tools
**Prerequisites:** [003](../003_numpy-fundamentals/README.md)
**Estimated time:** 3–4 hours

## Objective

Learn `Series`/`DataFrame`, loading real CSVs, selecting/filtering, `groupby`,
merging, and handling missing data — the everyday toolkit for turning raw data
into something a model can train on.
