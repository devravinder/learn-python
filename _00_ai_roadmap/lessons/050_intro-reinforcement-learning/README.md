# Lesson 050 — Intro to Reinforcement Learning: MDPs, Reward, Policy, Value

**Module:** 8 — Reinforcement Learning & Game AI (→ Chess Bot)
**Prerequisites:** [006](../006_probability-basics/README.md), [015](../015_gradient-descent/README.md)
**Estimated time:** 2.5 hours

## Objective

Everything so far in this curriculum has been supervised or unsupervised
learning — a fixed dataset, no notion of *acting* over time. This lesson
introduces the framework (MDPs) and vocabulary (state, action, reward,
policy, value) needed for Project 010's self-play Chess Bot, and for RLHF
(Lesson 072) later in the LLM track.
