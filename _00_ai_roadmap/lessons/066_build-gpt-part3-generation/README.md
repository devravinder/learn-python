# Lesson 066 — Build a GPT From Scratch, Part 3: Sampling & Generation

**Module:** 11 — Building Your Own LLM (Karpathy-style)
**Prerequisites:** [036](../036_activation-functions-softmax/README.md), [047](../047_seq2seq-encoder-decoder/README.md), [065](../065_build-gpt-part2-training/README.md)
**Estimated time:** 2 hours

## Objective

Turn your trained GPT into something that generates text — the
autoregressive loop, plus the sampling strategies (temperature, top-k,
top-p) that control the tradeoff between coherent-but-repetitive and
diverse-but-risky output. Project 013 uses exactly this code to actually
see your model's generated text for the first time.
