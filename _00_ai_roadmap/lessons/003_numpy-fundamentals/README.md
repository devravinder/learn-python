# Lesson 003 — NumPy Fundamentals

**Module:** 1 — Programming & Data Tools
**Prerequisites:** [001](../001_environment-and-python-setup/README.md), [002](../002_python-fundamentals-and-data-structures/README.md)
**Estimated time:** 3–4 hours

## Objective

Learn `ndarray`, vectorized operations, broadcasting, and indexing well enough to
never write a manual `for` loop over numeric data again. Every tensor library
(PyTorch included) borrows NumPy's mental model directly.
