# Lesson 028 — Boosting: AdaBoost, Gradient Boosting, XGBoost

**Estimated time:** 2.5 hours

## Objective

Where Random Forests build independent trees and average them, boosting
builds trees *sequentially*, each one correcting the previous ensemble's
mistakes — usually the strongest tabular-data technique in this curriculum.
