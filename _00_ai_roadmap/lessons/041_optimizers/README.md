# Lesson 041 — Optimizers: SGD, Momentum, RMSProp, Adam

**Module:** 6 — Neural Network Foundations
**Prerequisites:** [015](../015_gradient-descent/README.md), [040](../040_pytorch-training-workflow/README.md)
**Estimated time:** 2 hours

## Objective

Plain gradient descent (Lesson 015) works, but modern training almost always
uses something smarter. This lesson covers the actual optimizers you'll set
in every `torch.optim` call for the rest of the curriculum, including LLM
training.
