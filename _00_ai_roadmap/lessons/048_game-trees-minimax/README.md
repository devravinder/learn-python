# Lesson 048 — Game Trees & Minimax

**Module:** 8 — Reinforcement Learning & Game AI (→ Chess Bot)
**Prerequisites:** [002](../002_python-fundamentals-and-data-structures/README.md) (recursion)
**Estimated time:** 2–2.5 hours

## Objective

The first building block of the Chess Bot arc: how a computer can "look
ahead" in a two-player game and choose a provably optimal move, before any
machine learning is involved at all. Everything here is classical search —
Project 008's Chess Bot v1 is built directly from this lesson and Lesson 049.
