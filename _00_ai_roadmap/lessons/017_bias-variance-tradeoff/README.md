# Lesson 017 — Bias-Variance Tradeoff

**Module:** 3 — Linear Algebra & Calculus
**Prerequisites:** [015](../015_gradient-descent/README.md)
**Estimated time:** 2 hours

## Objective

The single most useful diagnostic framework for "why isn't my model working"
— is it too simple (underfitting/high bias) or too complex
(overfitting/high variance)? Every model-selection decision for the rest of
this curriculum traces back to this tradeoff.
