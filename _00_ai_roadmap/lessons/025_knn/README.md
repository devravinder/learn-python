# Lesson 025 — K-Nearest Neighbors

**Module:** 4 — Supervised Machine Learning
**Prerequisites:** [010](../010_linear-algebra-vectors/README.md), [019](../019_curse-of-dimensionality/README.md)
**Estimated time:** 1.5–2 hours

## Objective

The simplest possible model: predict based on whatever's nearby. Good for
building intuition about distance metrics and the bias-variance tradeoff via
a single hyperparameter (`k`), and a direct callback to Lesson 019's
curse-of-dimensionality warning.
