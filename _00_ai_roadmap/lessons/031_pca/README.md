# Lesson 031 — Principal Component Analysis (PCA)

**Module:** 5 — Unsupervised Machine Learning
**Prerequisites:** [012](../012_eigenvalues-eigenvectors-svd/README.md), [019](../019_curse-of-dimensionality/README.md)
**Estimated time:** 2 hours

## Objective

Your first unsupervised technique — no labels at all. This lesson implements
PCA from scratch using the eigendecomposition/SVD math from Lesson 012, then
uses it for real: visualization, noise reduction, and fighting the curse of
dimensionality.
