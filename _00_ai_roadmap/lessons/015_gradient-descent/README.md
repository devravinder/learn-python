# Lesson 015 — Gradient Descent

**Module:** 3 — Linear Algebra & Calculus
**Prerequisites:** [014](../014_partial-derivatives-gradients/README.md)
**Estimated time:** 3 hours

## Objective

Gradient descent is *the* training algorithm underlying almost every model
in this curriculum, from linear regression to LLMs. This lesson implements
it from scratch on a real problem (linear regression) and covers the
batch/stochastic/mini-batch variants and the learning-rate tradeoffs you'll
be tuning for the rest of this journey.
