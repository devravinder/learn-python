# Lesson 054 — Self-Play & AlphaZero-Style Training

**Module:** 8 — Reinforcement Learning & Game AI (→ Chess Bot, final lesson)
**Prerequisites:** [044](../044_cnn-architectures/README.md), [052](../052_policy-gradients-actor-critic/README.md), [053](../053_monte-carlo-tree-search/README.md)
**Estimated time:** 2.5–3 hours

## Objective

The synthesis lesson: combine a neural network (policy + value, Lessons
036, 044) with MCTS (Lesson 053) and self-play to get a system that
**improves itself with no human game data at all** — the approach behind
AlphaZero and Leela Chess Zero, and the direct blueprint for Project 010.
