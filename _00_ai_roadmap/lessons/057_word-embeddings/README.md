# Lesson 057 — Word Embeddings: Word2Vec & GloVe

**Module:** 9 — NLP Foundations (final lesson)
**Prerequisites:** [010](../010_linear-algebra-vectors/README.md), [056](../056_bag-of-words-tfidf/README.md)
**Estimated time:** 2.5 hours

## Objective

Fix TF-IDF's core limitation from Lesson 056: represent words as **dense
vectors** that capture meaning, so related words end up near each other in
vector space. This is the direct ancestor of the token embeddings inside
every Transformer (Lesson 058+) and your own LLM (Module 11).
