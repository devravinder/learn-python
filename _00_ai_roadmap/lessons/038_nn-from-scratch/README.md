# Lesson 038 — Neural Network From Scratch (micrograd-style)

**Module:** 6 — Neural Network Foundations
**Prerequisites:** [037](../037_backpropagation-math/README.md)
**Estimated time:** 3–4 hours

## Objective

Build a tiny autograd engine and a neural network on top of it, in pure
Python — no NumPy, no PyTorch. This directly follows
[Andrej Karpathy's micrograd](https://github.com/karpathy/micrograd) and his
"Neural Networks: Zero to Hero" series: once you've built backprop by hand
here, PyTorch's `autograd` (Lesson 039) will feel like exactly what it is —
the same idea, engineered for speed and tensors instead of scalars.
