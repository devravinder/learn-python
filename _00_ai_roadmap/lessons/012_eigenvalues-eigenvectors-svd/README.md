# Lesson 012 — Eigenvalues, Eigenvectors & SVD

**Module:** 3 — Linear Algebra & Calculus
**Prerequisites:** [011](../011_linear-algebra-matrices/README.md)
**Estimated time:** 3 hours

## Objective

Eigendecomposition and SVD are how you find the "natural directions" of a
matrix — directly used in PCA (Lesson 031), and the mathematical basis for
low-rank approximation (used in LoRA fine-tuning, Lesson 070).
