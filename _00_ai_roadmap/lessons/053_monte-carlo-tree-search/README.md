# Lesson 053 — Monte Carlo Tree Search (MCTS)

**Module:** 8 — Reinforcement Learning & Game AI (→ Chess Bot)
**Prerequisites:** [048](../048_game-trees-minimax/README.md), [052](../052_policy-gradients-actor-critic/README.md)
**Estimated time:** 2.5–3 hours

## Objective

The search algorithm actually used by AlphaZero-style engines — a way to
focus limited search effort on the *most promising* parts of a game tree,
using random simulation instead of a hand-written evaluation function.
Project 010 combines this lesson directly with Lesson 054's self-play.
