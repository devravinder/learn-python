# Lesson 051 — Q-Learning & Value Iteration

**Module:** 8 — Reinforcement Learning & Game AI (→ Chess Bot)
**Prerequisites:** [050](../050_intro-reinforcement-learning/README.md)
**Estimated time:** 2.5–3 hours

## Objective

Two concrete algorithms for actually computing (or learning) value
functions and optimal policies — value iteration when you know the MDP's
dynamics, and Q-learning when you don't (and must learn purely from
experience, exactly the Chess Bot v3 situation).
