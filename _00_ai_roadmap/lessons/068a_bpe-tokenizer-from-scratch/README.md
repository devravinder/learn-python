# Lesson 068a — Byte-Pair Encoding From Scratch (minbpe-style)

**Module:** 11 — Building Your Own LLM (Karpathy-style, final lesson)
**Prerequisites:** [062](../062_tokenization-for-llms/README.md), [064](../064_build-gpt-part1-architecture/README.md)
**Estimated time:** 2.5–3 hours

## Objective

A complete, reusable byte-level BPE tokenizer class — `train`, `encode`,
`decode` — following the structure of
[Andrej Karpathy's `minbpe`](https://github.com/karpathy/minbpe). Project
013 uses this in place of Lesson 064's character-level tokenizer for the
final version of your own GPT.
