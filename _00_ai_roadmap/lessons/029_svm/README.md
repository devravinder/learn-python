# Lesson 029 — Support Vector Machines

**Module:** 4 — Supervised Machine Learning
**Prerequisites:** [010](../010_linear-algebra-vectors/README.md), [023](../023_logistic-regression/README.md)
**Estimated time:** 2 hours

## Objective

A different way to think about classification: instead of modeling
probabilities (logistic regression), find the boundary that maximizes margin
to the nearest points of each class. The kernel trick here also previews an
idea (implicit high-dimensional feature spaces) that echoes later in
attention's similarity computations.
