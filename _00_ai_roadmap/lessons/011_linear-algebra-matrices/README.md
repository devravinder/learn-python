# Lesson 011 — Linear Algebra: Matrices & Operations

**Module:** 3 — Linear Algebra & Calculus
**Prerequisites:** [010](../010_linear-algebra-vectors/README.md)
**Estimated time:** 2–3 hours

## Objective

A matrix is a linear transformation and a batch of vectors at once — the
object every neural network layer, every dataset, and every attention score
table is built from. This lesson covers matrix multiplication, transpose,
inverse, determinant, and rank with an eye toward what each means for a
model, not just how to compute it.
