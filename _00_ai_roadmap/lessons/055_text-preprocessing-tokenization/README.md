# Lesson 055 — Text Preprocessing & Tokenization

**Module:** 9 — NLP Foundations
**Prerequisites:** [030](../030_naive-bayes/README.md) (Project 003's text classification)
**Estimated time:** 2 hours

## Objective

Before any model can process text, text must become numbers. This lesson
covers the preprocessing pipeline and tokenization strategies, from simple
whitespace splitting up to the subword methods every modern LLM uses.
