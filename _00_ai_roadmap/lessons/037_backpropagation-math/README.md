# Lesson 037 — Backpropagation: The Math

**Module:** 6 — Neural Network Foundations
**Prerequisites:** [014](../014_partial-derivatives-gradients/README.md), [036](../036_activation-functions-softmax/README.md)
**Estimated time:** 3 hours

## Objective

The algorithm that trains every neural network in this curriculum,
including the LLM you'll build in Module 11. This lesson derives it fully by
hand on a small network before Lesson 038 implements it in NumPy and
Lesson 039 lets PyTorch's autograd do it automatically.
