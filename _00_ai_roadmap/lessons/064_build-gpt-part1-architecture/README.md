# Lesson 064 — Build a GPT From Scratch, Part 1: Architecture

**Module:** 11 — Building Your Own LLM (Karpathy-style)
**Prerequisites:** [060](../060_transformer-architecture/README.md), [063a](../063a_makemore-style-char-lm/README.md)
**Estimated time:** 3 hours

## Objective

Wire Lesson 060's Transformer block architecture to real text data for the
first time: a character-level tokenizer, train/val splitting, and the
random-chunk batching scheme every GPT training script uses. By the end,
you have a complete, untrained GPT ready for Lesson 065's training loop.
