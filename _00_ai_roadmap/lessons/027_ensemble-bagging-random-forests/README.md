# Lesson 027 — Ensemble Methods: Bagging & Random Forests

**Module:** 4 — Supervised Machine Learning
**Prerequisites:** [017](../017_bias-variance-tradeoff/README.md), [026](../026_decision-trees/README.md)

## Objective

Fix decision trees' high variance by combining many of them — the general
"ensemble" idea that also underlies boosting (Lesson 028) and, much later,
self-play in game AI (Lesson 054).
