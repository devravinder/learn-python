# Lesson 045 — RNN Fundamentals

**Module:** 7 — Deep Learning for Vision & Sequences
**Prerequisites:** [037](../037_backpropagation-math/README.md), [039](../039_pytorch-fundamentals/README.md)
**Estimated time:** 2.5 hours

## Objective

CNNs (Lessons 043-044) handle spatial data; RNNs handle **sequential**
data — text, time series, anything where order matters. This is the last
stop before Transformers (Module 10) replace RNNs for most modern NLP, but
understanding why RNNs work (and where they struggle) makes attention's
motivation click much faster.
