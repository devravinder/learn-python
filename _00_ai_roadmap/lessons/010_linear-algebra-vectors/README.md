# Lesson 010 — Linear Algebra: Vectors & Vector Spaces

**Module:** 3 — Linear Algebra & Calculus
**Prerequisites:** [003](../003_numpy-fundamentals/README.md)
**Estimated time:** 2–3 hours

## Objective

Vectors are how ML represents everything — a data point, a word embedding, a
gradient, a model's weights. This lesson builds the geometric and algebraic
intuition (magnitude, direction, dot product, projection, similarity) you'll
reuse in every later math lesson.
