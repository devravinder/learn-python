# Lesson 001 — Environment & Python Setup

**Module:** 0 — Setup
**Prerequisites:** None
**Estimated time:** 1–2 hours

## Objective

Get a reproducible Python environment running so every later lesson "just works":
a virtual environment, the shared `requirements.txt` installed, and Jupyter available
for exploratory work.
