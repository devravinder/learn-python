# Lesson 033 — Hierarchical Clustering

**Module:** 5 — Unsupervised Machine Learning
**Prerequisites:** [032](../032_kmeans-clustering/README.md)
**Estimated time:** 1.5 hours

## Objective

Cluster without pre-specifying `k`, and get an interpretable tree
(dendrogram) of how clusters merge — a genuinely different approach from
K-Means's flat partitioning.
