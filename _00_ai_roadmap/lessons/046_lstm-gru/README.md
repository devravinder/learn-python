# Lesson 046 — LSTM & GRU

**Module:** 7 — Deep Learning for Vision & Sequences
**Prerequisites:** [045](../045_rnn-fundamentals/README.md)
**Estimated time:** 2 hours

## Objective

The fix for plain RNNs' vanishing gradient problem — gating mechanisms that
let networks learn what to remember and what to forget over long sequences.
Standard for sequence modeling for years before Transformers took over.
