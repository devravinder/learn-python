# Project 014 — RAG-Powered Assistant Over Your Own Documents

**Builds on lessons:** [073](../../lessons/073_llm-evaluation/README.md), [074](../../lessons/074_inference-optimization/README.md), [076](../../lessons/076_retrieval-augmented-generation/README.md) (Module 14 capstone, part 1)
**Difficulty:** Advanced
**Estimated time:** 5–7 hours

## Objective

A complete, working RAG system over a small set of your own documents —
chunking, embedding, retrieval, and LLM-grounded answering — plus a proper
retrieval-quality evaluation (Lesson 073), not just "it seems to work."

## Contents

1. [01_requirement.md](01_requirement.md)
2. [02_solutions/](02_solutions/)

## Data

Bring your own small set of text documents (a few README files, notes, or
short articles — 5-20 documents is plenty to prove the system works).
`02_solutions/data/` includes a small sample set (short encyclopedia-style
facts) so the pipeline is testable immediately.
