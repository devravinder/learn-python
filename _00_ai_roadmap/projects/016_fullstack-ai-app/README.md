# Project 016 — Full-Stack AI App (Capstone)

**Module:** 15 — Productionization & Career Transition
**Builds on:** Lessons [078](../../lessons/078_serving-model-as-rest-api/README.md)–[080](../../lessons/080_cloud-deployment/README.md), Project [013](../013_train-your-own-gpt/README.md)
**Estimated time:** 4–6 hours

## Objective

The career-transition capstone: a real, runnable full-stack application —
React frontend, Node/Express backend, a text-generation model in the
middle — built with the exact stack you already know (JS/Node/React),
with the "swap in the trained PyTorch GPT from Project 013" path
documented explicitly for when a GPU/PyTorch environment is available.
This is the project that most directly answers "can you actually ship an
AI feature," which is the question a full-stack-to-AI/ML career
transition ultimately has to answer.
