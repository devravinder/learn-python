# Project 001 — Retail Sales Exploratory Data Analysis

**Builds on lessons:** [001](../../lessons/001_environment-and-python-setup/README.md)–[005](../../lessons/005_data-visualization/README.md)
**Difficulty:** Basic (first project)
**Estimated time:** 3–5 hours

## Objective

Take on the role of a data analyst handed a raw retail transactions export and
asked "what's going on with our sales?" — with no further guidance. This is the
first real-time-flavored project: messy data, an open-ended question, and a
short written summary of findings at the end, which is exactly the shape of
real EDA work.

## Contents

1. [01_requirement.md](01_requirement.md) — the brief, as a stakeholder would give it
2. [02_solutions/](02_solutions/) — data generator, reference analysis script/notebook, and findings

## Data

The dataset is synthetic but intentionally messy (missing values, a few
negative amounts, some duplicate rows) so cleaning is part of the exercise, not
an afterthought. Generate it yourself — see [02_solutions/data/generate_data.py](02_solutions/data/generate_data.py).
