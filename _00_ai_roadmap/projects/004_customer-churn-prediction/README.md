# Project 004 — End-to-End Customer Churn Prediction

**Builds on lessons:** [020](../../lessons/020_linear-regression/README.md)–[030](../../lessons/030_naive-bayes/README.md) (all of Module 4)
**Difficulty:** Intermediate–Advanced (Module 4 capstone)
**Estimated time:** 4–6 hours

## Objective

The Module 4 capstone: a full, realistic supervised-ML workflow end to end —
EDA, preprocessing, handling class imbalance, comparing multiple model
families, picking a final model with a justified metric, and translating the
result into a business recommendation. This is the shape of a real
"predictive modeling" task at a job, not just a single-algorithm exercise.
