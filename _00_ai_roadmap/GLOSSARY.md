# Glossary

Terms are added here as lessons introduce them. Each entry links back to the lesson
that defines it.

## Module 0–1 — Setup, Python, Data Tools

- **Virtual environment** — an isolated Python installation + package set for one
  project, so dependencies don't clash across projects. See [001](lessons/001_environment-and-python-setup/01_concepts.md).
- **ndarray** — NumPy's core N-dimensional array type; contiguous, fixed-type, and
  the base data structure for almost all numerical ML code. See [003](lessons/003_numpy-fundamentals/01_concepts.md).
- **Broadcasting** — NumPy's rule set for applying operations across arrays of
  different but compatible shapes without copying data. See [003](lessons/003_numpy-fundamentals/01_concepts.md).
- **DataFrame** — Pandas' 2D labeled table structure (rows + named columns), built
  on top of NumPy arrays. See [004](lessons/004_pandas-fundamentals/01_concepts.md).

## Module 2 — Probability & Statistics

- **Random variable** — a variable whose value is the outcome of a random
  phenomenon. See [006](lessons/006_probability-basics/01_concepts.md).
- **Probability distribution** — a function describing how likely each outcome
  of a random variable is. See [007](lessons/007_probability-distributions/01_concepts.md).
- **Mean / Median / Mode** — measures of central tendency. See [008](lessons/008_descriptive-statistics/01_concepts.md).
- **Variance / Standard deviation** — measures of spread around the mean. See [008](lessons/008_descriptive-statistics/01_concepts.md).
