# Assignment 004 — Minimax + Alpha-Beta Tic-Tac-Toe Bot

**Covers lessons:** [048](../../lessons/048_game-trees-minimax/README.md)–[049](../../lessons/049_alpha-beta-pruning-evaluation/README.md)
**Estimated time:** 2 hours

## Objective

Turn Lessons 048–049's algorithms into an actual playable bot, and
specifically practice **depth-limited search with a heuristic evaluation**
— tic-tac-toe's tree is small enough to fully solve, but this assignment
deliberately restricts search depth anyway, since that's the technique
Project 008's Chess Bot v1 depends on for a tree far too large to fully
solve.
