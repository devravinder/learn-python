**Covers lessons:** [058](../../lessons/058_attention-mechanism/README.md)–[059](../../lessons/059_multi-head-self-attention/README.md)
**Estimated time:** 2–3 hours

## Objective

A checkpoint that goes one level deeper than either lesson's practicals:
implement **full multi-head self-attention with causal masking**, including
the Q/K/V/output linear projections, in plain Python with no NumPy/PyTorch
— then verify it numerically against a PyTorch reference implementation.
If your pure-Python version and PyTorch's agree to several decimal places,
you've proven you understand every step, not just called the right API.
