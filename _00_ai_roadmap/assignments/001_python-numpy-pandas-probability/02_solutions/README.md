# Reference Solutions

```bash
python solutions.py
```

Prints answers to Q1–6 and Q9–10, and saves the Q7/Q8 charts as PNGs in this
folder. Read the comments above each block — several answers explain *why*
a particular direction/result is expected given how the synthetic data was
generated, so you can sanity-check your own answers even if your exact
numbers differ (different random seed handling, rounding, etc.).
