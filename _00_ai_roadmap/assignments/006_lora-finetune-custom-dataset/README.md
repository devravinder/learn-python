## Objective

A hands-on checkpoint combining everything in Module 12 so far: load a
small pretrained open model, wrap it with LoRA adapters (Lesson 070),
instruction-tune it (Lesson 071's masked-loss formatting) on a small
custom dataset you write yourself, and confirm the behavior actually
changed.
